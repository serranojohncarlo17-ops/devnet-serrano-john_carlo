## Key vocabulary (in your own words)

- repository: it's like a folder that contains project.
- commit: commit is like a checkpoint where your project is ready to be passed.
- branch: having a branch allows you to work in the same project with different branch to avoid confusion or mixed up.
- push / pull: push is when you will already send the committed changes. It's like a package being delivered. While pull is getting the last changes from the repository in github platform into your own computer. pull is like importing.
- pull request: it works when you want a certain change from one branch to another.
- merge conflict: a problem that usually happens when git conflicts and when git doesnt know what changes to keep.
